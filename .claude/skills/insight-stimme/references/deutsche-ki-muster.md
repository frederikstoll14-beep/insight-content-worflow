# Deutsche KI-Muster

Ergänzung zu `avoid-ai-writing` (englisch). Gleiche Logik: Stufe 1 immer ersetzen, Stufe 2 ersetzen, wenn zwei oder mehr in einem Absatz stehen, Rhythmus zuletzt und am höchsten gewichten.

## Stufe 1: immer ersetzen

| Muster | Ersatz |
|---|---|
| In der heutigen (schnelllebigen/digitalen) Welt … | streichen, mit der eigentlichen Aussage beginnen |
| Es ist wichtig zu beachten, dass … / Es sei darauf hingewiesen … | streichen, Aussage direkt |
| Tauchen wir ein / Lassen Sie uns einen Blick werfen | streichen |
| … spielt eine entscheidende/zentrale Rolle | sagen, *was* es bewirkt |
| Gamechanger, Quantensprung, Meilenstein | beschreiben, was sich ändert |
| nahtlos, maßgeschneidert, ganzheitlich, innovativ, zukunftsweisend | konkret beschreiben oder streichen |
| revolutionieren, transformieren (als Floskel) | verändern, ersetzen, beschleunigen |
| Mehrwert schaffen/generieren | Nutzen mit Zahl oder Beispiel |
| Nicht nur X, sondern auch Y (als Reflex) | zwei einfache Aussagen |
| Zusammenfassend lässt sich sagen / Fazit: … ist ein spannendes Feld | streichen, letzte Aussage muss selbst tragen |
| Die Zukunft ist … / Es bleibt spannend | streichen |
| Ob A, B oder C – … | direkt aufzählen |
| unerlässlich, essenziell, von zentraler Bedeutung | wichtig, nötig, oder begründen |

## Stufe 2: ab zweimal pro Absatz ersetzen
effizient, optimieren, Potenzial, Herausforderung, Lösung, Mehrwert, entscheidend, vielfältig, umfassend, gezielt, nachhaltig, Chancen und Risiken, Rahmenbedingungen

## Satzbau und Rhythmus
- **Dreierketten.** „schnell, sicher und skalierbar" höchstens einmal pro Text.
- **Rhetorische Fragen als Überleitung** („Doch was bedeutet das konkret?") streichen.
- **Gleich lange Absätze** mit gleichem Aufbau (Behauptung, Erklärung, Beispiel) aufbrechen.
- **Doppelpunkt-Einleitungen** („Die Antwort: …", „Das Ergebnis: …") in normale Sätze umbauen.
- **Gedankenstriche** sparsam. Nie mehr als einer pro Absatz, nie als Ersatz für einen Punkt.
- **Nominalstil** („die Durchführung der Implementierung") in Verben auflösen („umsetzen").
- **Anglizismen** nur, wenn die Zielgruppe sie selbst benutzt (Cloud, Chat, Prompt ja; „leveragen", „enablen" nein).

## LinkedIn-spezifisch
- Kein Einstieg mit „Ich freue mich …", „Unpopular opinion:", „Lass uns ehrlich sein".
- Keine Zeilen aus einzelnen Wörtern. Keine Pfeil- oder Emoji-Listen.
- Kein Schluss mit „Was denkt ihr?" ohne echte, spezifische Frage.
